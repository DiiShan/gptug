## 内容维护原则

公开事实附原始来源与核查日期；工程建议、规划假设和真实测量分开标注。模型、客户端和服务能力随版本变化，引用时应保留版本与时间背景。

本仓库为公开资料库，不存放公司机密、设计资产、客户数据、内部服务地址或密钥。需要敏感上下文的实测和工程执行应在获准内部系统开展。
