## 本专题结论的边界

输入条件是可访问 Qwen3.8-27B 和名为 `dsv4` 的服务，可通过 OpenCode / Codex / Claude Code 接入，已知每 key 并发 10。具体权重、部署、网关和工具能力尚未通过内部实测确认。

总体方案中的 **8% / 20% / 29% 整体净工时节省**为保守/中性/进取规划情景，不是模型已实现的结果，也不是统计置信区间。中性情景按每人每月 160 小时计算，为 32 小时容量释放；10 人同类团队对应 2.0 FTE 工作量，不等于可以直接减少两名员工。完整假设、阶段权重和维护扣除见总体方案第 7 节。

公开行业案例、工程建议、假设计算和未验证能力在文档中分开标注。模型与客户端当前事实的原始来源集中在总体方案的参考资料中。
