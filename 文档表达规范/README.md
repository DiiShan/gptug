## 怎么使用

只需要 STE 风格的中文表达时，使用《ASD-STE100 的中文适配指南》；需要文档类型模板、证据分类、需求和决策记录时，使用《组合式中文工程写作指南》。两份指南用途不同，不是 STE 合规等级之分。

先确定文档类型，再把所选指南中的短提示词、原始材料和术语表交给 AI。芯片工作额外提供专用规则。对关键结果进行原文对照和人工复核；不能用“AI 说已检查”替代真实检查记录。

本目录不默认要求完整 ASD-STE100 合规，不采用“中文每句最多 20 个字”的机械规则，也不宣称模型幻觉会因一个标准名称自动下降。两份中文指南均为项目自定内容，不是标准官方译本；适配指南的主题映射也不等于全部 53 条规则的逐条翻译或完整合规审计。

## 内容边界

本目录把交流的实质内容按主题归档，并补充可执行的中文模板；不是逐字对话转储。芯片应用只在专用文档维护，通用指南不复制整套岗位内容。标准事实、个人体验、工程建议、虚构示例和真实测量分开标注。

“Anthropic 官方推荐 ASD-STE100”暂未得到足够一手材料确认；资料中保留核查范围与未确认状态。正式标准全文、词典或完整合规审计不包含在本目录中。

## 后续交流维护

用户要求本主题后续交流继续加入本目录。每次处理相关新交流时，先读取当前正文和维护约定，将新增结论合并到对应文档，并在交流记录中追加日期、问题、结论、修改位置及未决事项。已有内容优先修订，不反复新建同主题副本。

这是需要在实际处理该轮交流时执行的维护约定，不是后台自动监听或定时同步；也不表示所有客户端会自动读取这些文件。没有实际提交并核验时，不宣称 GitHub 已更新。
