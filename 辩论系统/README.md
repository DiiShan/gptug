## 桌面版日常流程

首次将 `codex-project` 整体复制到独立项目，包含隐藏目录，完成配置与原生能力验收。
之后只修改 `PROMPT.md` 第一行的主题，在Codex桌面版该项目的新对话中输入：

```text
读取 PROMPT.md 并执行。在当前桌面会话使用真实子agent。
需要初始化时调用prepare，不启动Codex CLI或scripts/debate.py start。
结束时按PROTOCOL第9节生成README、结构化final和完整正式过程，并完成结果发布检查。
```

这里的prepare/validate是本地Python辅助脚本，不是要求用户使用Codex CLI。当前工程版仍要求Python 3.11+及相应执行权限。偏好CLI的使用者仍可使用旧入口，但桌面版无需采用。

**一个主题内部用一个主对话调度多个真实子agent；不同主题使用新主对话。** 输出落在 `debates/<主题--哈希>/runs/<时间--ID>/`，相同主题重做也不覆盖旧run。

## 交付边界

本库提供完整提示词、原生agent配置、应用参数、启动/目录/快照脚本、结构验证器及合成测试。不是已经接入用户模型服务的生产验收报告，也不是独立实现的强制编排服务器。
源码测试和真实模型测试分开记录。运行输出默认gitignore，不自动发布到本公共仓库。此次上传只有系统模板、说明和测试，不包含用户未来辩题的资料/报告或认证信息。
