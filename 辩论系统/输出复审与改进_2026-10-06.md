### 根目录七个文件

`README.md`：读者入口，宜用较短结果速览与链接，不维护另一套长篇裁决。

`final.md`：面向读者的完整结果报告。当前开头明确“独立评委的实质裁决”，结尾附执行/核查说明。应从原文复贴型升级为有明确分项结构的编辑型报告；依据仍是同一份评委裁决。

`full_transcript.md`：按轮次汇编双方正式理由和主持状态。它的开头明确核查/裁决原文另见checks，不是包含所有工具事件的完整运行日志。与rounds有内容重叠是正常的阅读便利；应从原文确定性汇编，不再让模型重新概述一次。

`manifest.json`：初始化信息与输入哈希，不应被最终状态覆盖。

`run.json`：当前中央运行账本，含角色、轮次、主张、证据、争点及停止原因。

`run_prompt.md`：这次运行的路径和恢复入口；体积很小，保留即可。

`task_card.md`：明确辩题范围、定义、假设、评价标准，不等于只保存原句的输入文件。

## 三、最终结果应有哪些内容？

采用“一个结论来源、三个阅读层”：原始评委交付 → 结构化final → 简短README；完整过程从rounds汇编，不另写一份结论。

| 模块 | 读者要得到的答案 |

| 核心结论卡 | 这道题究竟怎样回答，最重要的限制是什么？ |
| 子命题/领域/场景判定表 | 哪些成立、哪些不成立、哪些有条件、哪些未知？ |
| 双方最强论据与反驳处理 | 为什么这样判，最强反例是否真正被处理？ |
| 共识与分歧 | 双方确实同意了什么，定义、证据、预测、价值还差在哪里？ |
| 不确定性与必要量化 | 哪些能给概率/区间，哪些只能给定性，依据是什么？ |
| 转折与纠错 | 哪些材料、释读或外推被修正，如何改变最终支持链？ |
| 适用条件、第三方案与下一步 | 在何种条件下应改判，下一项验证是什么？ |
| 证据入口及附录 | 如何查来源、全文和运行边界，而不被内部元数据淹没？ |

README默认生成，正文建议较短，但不是硬性压缩。final应充分展开；不能把必要解释全部推给别的文件，让读者跳转十几次才能知道结论。

结果编辑不是第二次裁决。把“在制度参与定义下有反例”缩成“古人都有国家概念”，或把“未核实”缩成“错误”，属于实质改写，不是改善展示。

## 四、截图中应保留什么，修正什么？

值得保留的是共识表、核心分歧、按领域分项、观点能否共存、综合结论与具体建议。它们让读者看到结构，而不是只读一段长篇结语。

不能直接照搬的是没有定义的星级和百分比。例如截图中“60–70%概率有效”，从截图无法知道是个体获益概率、研究阳性比例、某项效应存在的主观概率还是其他量；这些不是同一个问题。截图还引用“86/888”，但未显示统计单位、入选方式和从计数到整体结论的推导，不能据此验证所给区间。这里不判断对应医疗事实，只指出展示尚不可复核。

同样，“科学性”“有用性”“推荐程度”是不同维度。可以分栏，但每一栏必须有定义和依据；不能让一排星星看起来像正式证据分级。是否建议行动还涉及风险、替代方案、成本和用户目标，不能机械等于效果概率。

截图中的“统一意见”也需要真实确认。没有确认时应叫“评委综合建议”或“可兼容的表述”，而不是替双方宣布达成共识。

## 五、概率不是一个开关，而是不同对象

| 类型 | 可以怎样使用 | 不应混淆为什么 |
|---|---|---|
| 观测比例/频率 | 给出样本、分子分母、时间、统计单位和外推限制 | 不是整个命题的真值概率 |
| 预测或模型概率 | 定义事件、截止时间、条件、判定标准，说明数据与方法 | 不是保证，也不是模型已经被实际运行的证明 |
| 主观认知概率 | 对明确命题公开估计者、基准、证据更新、假设、敏感性及未校准性质 | 不是客观统计；不必已有校准才能表达，但必须诚实标注 |
| 证据置信程度 | 按具体主张说明直接性、代表性、一致性与不足，给定性判断 | 高/中/低不自动映射到固定百分比 |
| 辩论评分/胜率 | 单列评分尺度与理由；胜率须另有明确评判事件和方法 | 不能用分数除以满分得到“事实正确概率” |

**应恢复的是有依据、有语义的不确定性展示，不是所有题都恢复一个正方XX%、反方XX%。**

没有代表性样本并不在逻辑上禁止给主观概率；只是要明确那是评估者的判断，而不是历史人口比例。反过来，写“主观”也不能成为随便编数的许可证。不能说明基准、更新理由和敏感性时，定性结论更合适。

宽区间也不天然严谨。需要说明它是统计置信区间、贝叶斯可信区间、预测区间，还是在不同合理假设下的主观敏感性范围。后者不能冒充“95%置信区间”。未核实不等于50%；多agent的一致不是独立样本；多个子命题的概率也不一定应合计100%。

方法参考（不用于替原案补充历史证据）：IPCC的[不确定性表达指南](https://www.ipcc.ch/site/assets/uploads/2017/08/AR5_Uncertainty_Guidance_Note.pdf)区分定性的confidence与概率性的likelihood，概率依据可以来自统计、模型或专家判断。本次使用其公开索引中的方法说明，网页PDF在本环境返回403，未重新逐页检查。NIST的[均值置信区间说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)明确解释频率学派95%区间的覆盖意义，不等于给当前具体区间赋95%的参数包含概率。这些参考不表示本项目已经采用或通过任何官方评级/校准。

## 六、对本题不应临时补造百分比

原案真正得到的是分项有限判断：在明确制度参与含义下的限定反例；关于情感归属的总体问题仍未决；苦难是否相同缺少固定尺度与可比结果；民生评价原则可以保留。

这足以产生清楚的报告，不必补“反方90%获胜”或“古人有国家观念概率70%”。这两个数字既不是同一对象，也不是原评委的交付。未来若要量化，需先规定命题/总体/指标；或者另作清楚标注的主观评估，并保留原案版本。

配套的[结果展示示范](案例结果展示示范_国家兴亡与百姓处境.md)仅重排原案已支持的内容，不制造新的历史概率、评分或置信等级。保留原句未获支持与其反面未获全面证明的区别。
